# android — Golden Thread for Android

The Pixel client. See `golden-thread/` for the app (Java, framework
APIs only, no dependencies): a foreground overlay service floats the
soul-print bubble over the X app; the panel carries today's prune and
the next spaced-repetition card; a share-sheet activity receives shares
from X and logs encounters. Build: `golden-thread/build-on-ranch.sh`
(JDK + SDK + Gradle fetched user-space on a ranch node), or open the
project in Android Studio.

Delivery rule (Will, 2026-11-14): every APK delivered to Will is a file whose name ends in .apk — versioned, e.g. golden-thread-1.3.0.apk — and the chat attachment carries that exact filename.
